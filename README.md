# 🔐 Pin Code Verification System

A simple Python program that asks for a pin code and shows the index of each character in your name.

## ⚙️ How It Works
1.  Asks for pin code
2.  If pin is `89076`, access granted
3.  Takes your name as input
4.  Prints each character with its index number

## 🚀 How to Run
```bash
python main.py
